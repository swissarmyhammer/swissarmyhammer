Stores instructions as `.ralph/<session_id>.md` with `set ralph`. Used by Stop hooks to prevent Claude from stopping while work remains. When a Stop hook fires and an instruction is active, `check ralph` returns `"decision": "block"` — the hook runs in a separate process whose session id never matches the setter's, so a miss on the named session falls back to the newest active instruction in `.ralph/`. Call `clear ralph` when work is done to release the block; without an explicit `session_id` it removes every active instruction.
