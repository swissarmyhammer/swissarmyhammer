## What

`crates/swissarmyhammer-agent/src/lib.rs` selects between two ACP executors,
claude-agent and llama-agent, from the model configuration. Make Claude the
only branch.

Remove from `crates/swissarmyhammer-agent/src/lib.rs`:
- the `use llama_agent::types::AgentAPI;` import (line 81),
- the llama arm of the executor match near line 409 and its
  `create_llama_agent(llama_config, mcp_config)` call (line 417),
- `wrap_llama_into_handle` (line 543),
- `dispatch_llama_request` (line 761) and `dispatch_llama_notification`,
- the module doc lines that name llama-agent (lines 4 and 32).

Then remove `llama-agent` from
`crates/swissarmyhammer-agent/Cargo.toml`.

A model configuration that asks for the llama executor must now fail with a
clear error, not fall through silently. Return an error that names the
unsupported executor.

Find every remaining site with
`grep -rn "llama" crates/swissarmyhammer-agent/`.
