title: Public-surface diff probe for completeness
---
A TreeSitterProbe that reports what a diff did to the public surface of each changed file.

- Parse the before and after versions. Compare public symbols: added, removed, signature changed, visibility changed.
- Reuse the entity-level semantic diff machinery behind the git `get diff` op. Do not write a second symbol differ.
- One ProbeRow per surface change: symbol path, change kind, old and new signature.

Wire-up:
- Add the probe to the `completeness` set's `probes:` list.
- Update the completeness rule prompts to consume the rows as computed facts — same style as cognitive-complexity: the changes are computed for you, judge them, do not re-derive them.

Acceptance:
- A diff that changes one public signature yields exactly that row.
- A diff with no public-surface change yields no rows, and the prompt treats that as a measurement.
